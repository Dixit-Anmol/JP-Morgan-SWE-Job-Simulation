JP Morgan Software Engineering Virtual Experience

This repository contains the completed tasks from the J.P. Morgan Software Engineering Virtual Internship on Forage. The project structure and starter code were provided by J.P. Morgan as part of the simulation. I did not build the entire project from scratch — I forked the official repository and completed the assigned tasks as per the internship guidelines.

📌 Disclaimer This project is part of the official virtual internship experience provided by J.P. Morgan on Forage. The initial project scaffold and requirements were provided by J.P. Morgan. My contributions focus on successfully completing the five practical tasks outlined during the internship.

✅ Tasks Completed During the internship (May 2025 – June 2025), I completed the following:

✔️ Project Setup Set up the development environment and prepared the workspace for the project.

✔️ Kafka Integration Implemented Kafka consumer logic to process real-time streaming data.

✔️ H2 Database Integration Integrated the H2 in-memory database to store and manage transactional data.

✔️ REST API Integration Developed service layers to expose backend operations through REST APIs.

✔️ REST API Controller Built and tested controller endpoints to handle client HTTP requests and provide responses.
